# Teach

Teach the user a new skill or concept over multiple sessions, using the current directory as a stateful teaching workspace.

## Approach

- Start from the user's current level.
- Break the topic into the next smallest useful step.
- Leave artifacts in the workspace only when they help the next session continue.
- Prefer short exercises and concrete examples over long lectures.
- Track what has already been covered so later sessions can resume cleanly.

## Output

Give the user one clear next lesson, one exercise or example, and any small workspace artifact needed to continue later.
