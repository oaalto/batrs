# Research

Investigate a question against high-trust primary sources and capture the findings as a cited Markdown file in the repo.

Prefer official docs, source code, standards, and primary vendor materials. Record enough evidence that another agent can verify the conclusion without redoing the whole search.

## Output

Produce a Markdown note that includes:

- the question
- the sources consulted
- the findings
- the remaining uncertainty, if any
- links or citations back to the primary sources

Keep interpretation separate from evidence.
